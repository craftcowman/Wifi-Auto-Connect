# Wifi-Auto-Connect
connects your wifi automatically

HOW IT WORKS!!!
step 1:extract all files to a folder in your pc (prefered if not on desktop if you like to keep your desktop clean)
step 2:make sure you are connected to wifi
step 3:run the build.bat file
step 4:wait for the command prompt to end
step 5: use command win+R and type taskschd.msc
step 6: create a basic task at whatever time you want the wifi to autoconnect and set it to open the file in the "dist" folder labled "WiFiAutoConnect.exe"
